# Broadening — what to know to be smart and intelligent

> A browsable reference, not a roadmap. Pick by mood. Goal: walk into Wharton (and any room thereafter) with enough range to hold a real conversation across history, geopolitics, philosophy, science, tech, economics, and culture. Not depth — fluency.
>
> Each category has a few topics, one **Anchor** (the canonical single thing to start with if you only do one), and top **Channels** (YouTube / podcasts) for ongoing drift.

---

## India (you'll be asked, often)

| Topic | What you're aiming for |
|---|---|
| British Raj → Independence (1947) → Nehru → 1991 liberalization → Modi era | A clean 3-min answer to "tell me about modern India" |
| Indian political system | Parliament + federalism + how Congress vs BJP differ |
| Post-1991 economic story | IT services boom, demographic dividend, why China pulled ahead |
| Caste, religion, regional diversity | The honest answer when classmates ask awkward questions |
| Foreign policy | Non-alignment legacy, Quad, China/Pakistan, BRICS, S Jaishankar's framing |

**Anchor:** *India After Gandhi* by Ramachandra Guha (canonical post-Independence history). **Channels:** ThePrint, Newslaundry, The Deshbhakt, Open Magazine. **Podcast:** Lex Fridman x Jaishankar.

## How to use this file

- **Mood-based.** Open this when you have 20 min and curiosity, pick anything that catches the eye.
- **Anchors first.** If you want to do this seriously per category, start with the Anchor. Don't try to read multiple things in parallel.
- **No checkboxes.** This is reference, not a roadmap. New cards: drop a .md into content/<category>/ with frontmatter.
- **Add as you go.** When a podcast/book/channel earns a spot, add it to its category.
